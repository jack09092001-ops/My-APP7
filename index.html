路線地圖規劃

尚未設定 Google Maps API 金鑰

按地圖左上角「✏️ 手繪」後，用手指在地圖上畫出路線。可分多筆畫，離開手繪模式即可移動地圖。

還沒有暫存路線，先到「繪製」畫一段吧。

    調整順序（▲▼）與方向（⇄），地圖上會即時預覽。前後段若在路上交會，會直接在交會點剪接，不產生折返路線；完全沒相交的空隙在儲存時才沿道路補上。

      還沒有命名路線。到「暫存路線」勾選路段後合併 / 命名。

        設定

        此金鑰需在 Google Cloud 啟用：Maps JavaScript API、Roads API（開啟海拔需再啟用 Elevation API）。金鑰只存在這支手機的瀏覽器中。
